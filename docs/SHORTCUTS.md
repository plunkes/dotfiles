# Shortcuts

Sway, `Super` = Windows key. Source: [`dotfiles-stow/sway/.config/sway/config`](../dotfiles-stow/sway/.config/sway/config) (Super+Shift+c reloads).

## Apps

| Keys | Action |
|---|---|
| Super + Enter | Kitty |
| Super + d | launcher (fuzzel) |
| Super + e | files (yazi) |
| Super + w | LibreWolf |
| Super + o | Logseq |
| Super + m | Spotify |

## Session

| Keys | Action |
|---|---|
| Super + Esc | lock |
| Super + Shift + Esc | hibernate |
| Super + n | notifications on/off (waybar shows 󰂛 while off) |
| Super + a | keep screen on: no auto lock / screen off, still locks on suspend (waybar shows 󰅶) |
| Super + q | close window |
| Super + Shift + c | reload config |
| Super + Shift + e | exit Sway |

## Windows

| Keys | Action |
|---|---|
| Super + h j k l | focus left / down / up / right |
| Super + Shift + h j k l | move window |
| Super + f | fullscreen |
| Super + Shift + Space | floating on/off |
| Super + Space | switch focus tiled / floating |
| Super + r | resize mode (h j k l, Enter/Esc to leave) |
| Super + drag | move (left button) / resize (right button) |
| Super + - / Super + Shift + - | show / send to scratchpad |

## Layout

| Keys | Action |
|---|---|
| Super + v / Super + c | next window opens below / beside the focused one (grid: mix both) |
| Super + t | toggle split direction |
| Super + s | stacking |
| Super + Shift + t | tabbed |

## Workspaces

| Keys | Action |
|---|---|
| Super + 1…0 | go to workspace 1…10 |
| Super + Shift + 1…0 | send window to workspace |
| Super + Alt + 1…0 | send window to workspace and follow it |
| 3-finger swipe left / right | next / previous workspace |
| Super + Ctrl + h / l | move workspace to the monitor on the left / right |

## Wallpaper

| Keys | Action |
|---|---|
| Super + Shift + w | picker (recolors everything) |
| Super + Shift + n | next |
| Super + Shift + r | random |

## Screenshots and media

| Keys | Action |
|---|---|
| Print | region → annotate in satty |
| Shift + Print | full screen → `~/Pictures/Screenshots` |
| Volume / Mute / Mic mute keys | wpctl |
| Play / Next / Prev keys | playerctl |
| Brightness keys | brightnessctl |
