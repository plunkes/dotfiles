dotfiles

Arch Linux · any laptop or desktop · hardware auto-detected, per-machine tweaks in hosts/

Install

  1. Install Arch with the official guide: UEFI, GRUB, Btrfs (@, @home) or ext4. Optional: add hosts/<hostname>.conf (keyboard, charge limit, extras).
  2. GRUB background lives in grub/lunkes/background.png (change it). Desktop wallpapers go in wallpapers/.
  3. Run as your user: 
    git clone git@github.com:plunkes/dotfiles.git ~/dotfiles
cd ~/dotfiles
bash scripts/detect.sh   # check detected hardware
./install.sh
  4. Reboot, then: 
    sudo tailscale up
gh auth login && gh ssh-key add ~/.ssh/id_ed25519.pub
$EDITOR ~/.config/fish/conf.d/local.fish   # machine-only vars, not tracked
StepScriptDoes
00bootstrapsystem update, paru
01packagespackages/base.txt + matching packages/hw/*
02aurpackages/aur.txt (review PKGBUILDs)
03grubtheme, fonts, grub-mkconfig
04swapzram; laptops: swapfile (Btrfs or ext4) + hibernation
05dotfilesstow configs into ~, keyboard/monitors from the host profile
06devRust, Python, Node, groups, fish plugins
07distrobox-ros2ros-jazzy container
08systemgreetd, power (TLP or power-profiles-daemon), services, firewall, SSH key
09themewallpaper folder, first colors, GTK dark, Spicetify (open Spotify once first)

Resume from a step: ./install.sh 05. Each script also runs alone.
